# mortgage-default-risk-modelling
End-to-end machine learning project using Freddie Mac loan data to model mortgage default risk, compare classification models and explore key risk drivers.

## Environment

This project was developed using Python and Jupyter Notebook.

Main libraries:
- pandas
- NumPy
- scikit-learn
- imbalanced-learn
- XGBoost
- scikit-optimize
- matplotlib
- seaborn

The enviroment was included as 'project-mdrm_env.yaml'
